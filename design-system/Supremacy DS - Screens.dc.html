Screens

Four production surfaces assembled entirely from the component sheet — nothing new is invented here. Each is a target for chrome: if Claude Code's HUD, panels or tables differ from these, the build is wrong. The board itself is a canvas owned by board-render.js — the system supplies its tokens, not its geometry, and its region is drawn here as a void frame rather than mocked. Frames are 1440×900 and scroll horizontally at narrow widths so geometry stays true.
