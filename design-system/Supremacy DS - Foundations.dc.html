03

Ink, signal, hue

Four text steps and a white signal carry the entire interface. Hue is spent only on game state — faction, status, coin — so anything coloured on screen is something the player can act on. Contrast is measured against --sl-ink-200; the ratio on each chip is the floor, not a target.

07

The frame

Every region in the client is one of four frames. This is the load-bearing pattern of the system — get it right and screens assemble themselves.

Panel
Standard panel

ink-200 + seam-strong + a label tab notched into the top edge. The default container for anything out of match.

bg ink-200 · border 1px seam-strong · pad 16/24
tab: mono label-sm on ink-200, top −6px, left 18px
Armed frame

Four signal bracket ticks. Marks the one thing awaiting the player's input — a selected province, an armed order, a live queue.

ticks: 9px arms, 1px signal, offset −1px

08

Motion

Instrument motion: short, flat, no overshoot, no bounce. This is a real-time game — nothing that animates may delay the player reading state. Anything inside a match is capped at dur-3.
