Icons

One drawn set, no library. Every icon is a 16×16 viewBox stroked at 1.5 grid units with square caps and mitre joins — the same zero-radius language as the frames, so an icon sits inside a panel without softening it. Nothing is filled except the play triangle. Copy the SVG; do not restyle it.

01

Construction

Every icon is drawn on the same grid with a 1px safe margin, so a set of them reads as one weight in a row. vector-effect="non-scaling-stroke" pins the rendered stroke at 1.5 device pixels at every size — without it a 20px icon draws at 1.875 and outweighs the 1px seams around it.

Wrapper — copy this exactly
<svg width="16" height="16" viewBox="0 0 16 16" fill="none"
     stroke="currentColor" stroke-width="1.5"
     stroke-linecap="square" stroke-linejoin="miter"
     vector-effect="non-scaling-stroke"
     aria-hidden="true">…</svg>

stroke="currentColor" is load-bearing: the icon inherits its parent's ink, so it dims with disabled text and takes faction hue inside a seat pill with no extra rule. An icon that carries its own colour is a bug. When an icon is the only content of a control, give the control an aria-label and leave the svg aria-hidden.

In use

Icons are a second channel, never the only one. A label beats an icon wherever there is room; icon-only is for the toolbar rail and repeated row actions where the label would be said forty times.
